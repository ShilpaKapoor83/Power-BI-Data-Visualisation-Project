# 📊 Power BI Data Visualisation Project

## 📌 Project Overview

This project demonstrates my approach to preparing, analysing and presenting data using Power BI.

The project forms part of my ongoing development through my Level 4 Data Analyst Apprenticeship and demonstrates how data can be transformed into clear and meaningful information for stakeholders.

## 🎯 Project Objectives

The main objectives of this project are to demonstrate my ability to:

- Prepare and clean data for analysis
- Transform data using Power Query
- Analyse quantitative and qualitative information
- Design clear and effective Power BI reports
- Select appropriate data visualisations
- Present key findings clearly
- Consider stakeholder requirements and feedback
- Improve report design based on feedback

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- Microsoft Excel
- DAX

## 🧹 Data Preparation

The data preparation stage involved reviewing the source data, identifying data quality issues and preparing the information for analysis.

This included activities such as:

- Checking data types
- Identifying missing or inconsistent values
- Reviewing column names
- Removing unnecessary information
- Transforming data where required
- Checking the quality of the prepared dataset

## 📊 Data Analysis

The prepared data was analysed to identify useful patterns, trends and measures.

Both quantitative and qualitative information can contribute to understanding the results and deciding how information should be presented to the intended audience.

## 📈 Data Visualisation

Power BI was used to turn the analysed data into clear and accessible visualisations.

When designing the report, consideration was given to:

- Choosing appropriate visualisations
- Keeping the layout clear and consistent
- Highlighting important information
- Making information easy for stakeholders to understand
- Avoiding unnecessary visual clutter

## 💬 Stakeholder Feedback

Feedback is an important part of report development.

Feedback can be used to identify improvements to the layout, visualisations and presentation of information. Changes can then be made to improve the usability and clarity of the report.
